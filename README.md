# Asana Lite

Упрощённый локальный аналог Asana: проекты, секции, задачи и подзадачи, сроки,
схема процесса (mindmap) с развёртыванием в задачи, комментарии в стиле
OpenProject, вход через Keycloak.

## Запуск

1. Двойной клик `start-all.bat` — поднимет Keycloak (порт 8080) и приложение
   (порт 3000), откроет браузер.
2. Вход: `user1` / пароль из `credentials.txt` (страница входа — Keycloak).
3. Останов: `stop-all.bat` (или Ctrl+C в окне приложения).

Первый запуск: если `config.json` отсутствует, выполните один раз
`powershell -ExecutionPolicy Bypass -File setup-auth.ps1` — он создаст realm,
клиента, пользователей и config.json.

## Структура

```
Asana Lite/
├── server.js           # HTTP-сервер: статика + REST API + OIDC-вход + хранилище
├── auth.js             # OIDC (PKCE), проверка id_token по JWKS, сессии
├── config.json         # порты, realm, секреты клиента и сессий
├── data.json           # данные (создаётся автоматически)

├── start-keycloak.ps1  # запуск/проверка Keycloak
├── start-all.bat       # ЗАПУСК ВСЕГО
├── stop-all.bat        # ОСТАНОВИТЬ ВСЁ
├── java/               # портативный JDK 21 (Temurin)
├── keycloak/           # портативный Keycloak 26.7.2
└── public/             # фронтенд (SPA)
    ├── index.html
    ├── styles.css
    └── app.js
```

## Как работать

- Проект → вкладки **Список / Доска / Схема**.
- Схема необязательна: опишите шаги «что за чем и как», у каждого узла есть
  описание. Кнопка «Развернуть в задачи»: корень → секция, узел → задача,
  подшаги → подзадачи (глубже — строками в описании подзадачи). Повторный
  запуск обновляет те же секции.
- Описание проекта и обсуждение: клик по названию проекта (или меню «⋯»).
- Комментарии: в панели задачи и проекта. Enter — отправить.
- Подзадачи: панель задачи или «+» у родителя; свёртывание — каретка слева.

## Перенос как отдельный проект

Папка самодостаточна: скопируйте её целиком на машину с Windows, запустите
`start-all.bat`. Если data.json отсутствует — создастся демо-набор.
`_dist/` и `kc.log` в копию можно не брать.
